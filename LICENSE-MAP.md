# License Map

This document defines the intended license boundary for the repository. It does not grant trademark rights and does not replace a rights-holder review.

| Path or asset type | Intended license | Notes |
|---|---|---|
| `tokens/**`, `scripts/**`, future source code and automation | Apache-2.0 | See [`LICENSE`](./LICENSE) |
| `docs/**`, root Markdown guidance, issue templates, and diagrams created for this project | CC-BY-4.0 | See [`LICENSE-DOCS`](./LICENSE-DOCS) |
| `assets/**` | Per-asset declaration required | No asset may be added without author, source, license, and trademark metadata |
| project names, logos, and official visual identity | Not licensed by default | See [`TRADEMARKS.md`](./TRADEMARKS.md) |
| third-party names, marks, screenshots, fonts, and examples | Their respective terms | Must not be assumed reusable |

Before the first public release, replace the copyright-holder placeholder in [`NOTICE`](./NOTICE), review all new assets, and add file-level SPDX or REUSE metadata once the copyright holder is confirmed.
