# 大型企业系统设计规范

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 目标

面向多组织、多角色、复杂数据和长期业务流程，优先保证稳定、可预测、可审计和高效率。

## 2. 核心能力

```text
Tenant / Organization
Workspace
RBAC / ABAC
Field-level Permission
Saved View
Advanced Filter
Bulk Action
Form
Workflow
Approval
Audit Log
Import / Export
Notification
Session / Device
Change History
```

## 3. 应用壳层

必须持续展示：

- 当前租户 / 组织；
- 当前环境；
- 用户角色；
- 数据范围；
- 全局搜索；
- 通知与待办；
- 帮助和审计入口。

切换租户前应提示未保存内容和数据范围变化。

## 4. 数据表格

企业表格必须支持：

- 服务端排序与筛选；
- 保存视图和共享视图；
- 列固定、调整、隐藏；
- 批量选择与跨页选择说明；
- 行级、字段级权限；
- 总数、当前筛选范围和导出范围；
- 大数据虚拟化；
- 空值、未知、已脱敏、无权限的不同表达；
- 变更历史与字段 Diff；
- 键盘操作。

## 5. 复杂表单

- 使用步骤化表单处理高认知负荷流程；
- 支持草稿、自动保存、离开提醒；
- 错误在字段附近显示，并提供页面级错误摘要；
- 条件字段出现时保持焦点和阅读顺序可预测；
- 权限受限字段说明原因；
- 提交前展示变更摘要。

## 6. 批量操作

批量操作栏展示：

```text
已选数量
选择范围
目标操作
影响预览
成功 / 失败数量
导出失败明细
撤销或补偿动作
```

跨页全选必须明确是“当前页”“当前筛选结果”还是“全部数据”。

## 7. 权限设计

### Permission Matrix

维度可以包括：

```text
主体 × 资源 × 动作 × 范围 × 条件 × 时间
```

权限变更需要：

- 变更前后 Diff；
- 影响用户或资源数量；
- 继承来源；
- 冲突解释；
- 生效时间；
- 审批记录。

## 8. 流程与审批

工作流页面展示当前节点、上一节点、下一节点、条件分支、SLA、审批人和历史。退回必须指定目标节点和原因。

## 9. 审计日志

审计日志至少支持：

- 人员或 Agent；
- 时间与时区；
- 租户和环境；
- 资源；
- 动作；
- 结果；
- IP / 设备或服务身份；
- 变更 Diff；
- 请求 ID / Trace ID；
- 导出与保留策略。

## 10. 视觉策略

- 默认 Compact 或 Standard；
- 玻璃强度 None / Low；
- 3D 默认关闭；
- 动效仅用于状态连续性；
- 同时支持 Light、Dark、High Contrast；
- 强调异常、待处理和权限边界，而不是装饰。

## 11. 验收

- 多租户切换不造成数据误操作；
- 权限与继承关系可解释；
- 批量操作可预览和导出结果；
- 长流程支持恢复和草稿；
- 审计日志能够复原关键操作；
- 大表格在目标数据量下满足性能预算。
