# v0.1 → v0.2 升级迁移说明

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 迁移目标

将单一的暗色任务管理 Dashboard 规范升级为可服务多个产品类型的设计系统。迁移不是删除 v0.1，而是重新分层：

```text
v0.1 的视觉规则
→ 提炼为品牌与体验能力
→ 基础交互归入 Core System
→ 任务管理归入 Enterprise / Agent Pattern
→ 3D 与强玻璃归入 Marketing 或 Immersive Experience
```

## 2. v0.1 内容去向

| v0.1 内容 | v0.2 去向 | 处理方式 |
|---|---|---|
| 暗色背景、品牌绿色 | Token 规范 | 改为多主题语义 Token |
| 玻璃材质三级 | Token + 性能规范 | 改为可配置强度并增加降级 |
| 字体、间距、圆角 | Core Token | 保留并扩展密度轴 |
| 左侧导航、KPI、任务列表 | 核心组件 / 企业 Profile | 去除任务管理绑定 |
| 右侧任务详情 | Context Panel Pattern | 支持任务、Run、告警、数据对象 |
| 3D 文件卡 | Marketing / Agent Topology | 从基础组件降级为可选能力 |
| AI 建议卡 | Agent Profile | 扩展为计划、工具调用、审批、解释和产物 |
| 响应式 | 核心布局 | 改为容器与场景双层响应式 |
| 无障碍 | 独立规范 | 增加测试矩阵与验收方法 |
| 性能原则 | 独立规范 | 增加量化预算和降级等级 |

## 3. 必须废弃的假设

以下假设不得继续作为系统级规则：

- 所有产品都采用暗色主题；
- 所有产品都以任务为中心；
- 所有页面都适合三栏布局；
- 玻璃与 3D 越多越能体现 AI；
- 绿色同时代表品牌、成功、在线和进行中；
- AI 只需要“生成、接受、拒绝、重新生成”；
- 右侧详情栏能够承载全部复杂工作流；
- 官网、发布会与生产系统可以共享同一性能预算。

## 4. 新增系统轴

```text
Theme       = light | dark | high-contrast
Density     = compact | standard | comfortable | presentation
Experience  = solid | glass | immersive
Product     = agent | enterprise | finance | ops | marketing
Motion      = none | reduced | productive | expressive
Transparency= none | reduced | full
Risk        = r0 | r1 | r2 | r3 | r4
```

## 5. 迁移实施顺序

### 阶段 A：基础重构

1. 将颜色值改为 `surface / on-surface / action / status` 语义。
2. 将组件尺寸拆分为 Compact、Standard、Comfortable。
3. 将玻璃、光效和 3D 改为 Feature Flag 或体验属性。
4. 将“任务详情栏”重命名为“上下文面板”。

### 阶段 B：Profile 建立

1. Agent：增加 Run、Plan、Tool Call、Approval、Artifact。
2. Enterprise：增加多租户、权限、批量操作、审批和审计。
3. Finance：增加精度、时区、来源、新鲜度和复核。
4. Ops：增加告警、事件、指标、日志、链路和 Runbook。
5. Marketing：建立 Hero、Demo、叙事、CTA 与 SEO 规则。

### 阶段 C：工程治理

1. Figma Variables 与代码 Token 对齐。
2. 建立组件成熟度和变更日志。
3. 加入无障碍、视觉回归和性能门禁。
4. 为所有高风险 AI 行为建立审批与审计模式。

## 6. 兼容策略

v0.1 可继续作为视觉灵感稿使用，但不能再作为生产系统的唯一规范。已有页面可通过以下方式渐进迁移：

```text
保留布局
→ 替换 Token
→ 减少无语义玻璃
→ 增加完整状态
→ 引入 Profile 组件
→ 通过安全、无障碍、性能验收
```

## 7. 迁移完成定义

- 不再存在硬编码品牌绿承担多个状态语义；
- 每个页面已声明适用 Profile、Density 和 Experience；高风险操作已声明 R0–R4、影响范围、审批与审计要求；
- AI 执行与 AI 生成内容能够区分；
- 高风险动作展示影响范围、权限和可撤销性；
- 数据系统展示来源、时间、时区、精度与质量状态；
- 运维页面能够从异常概览下钻到证据和处置；
- 官网的 3D 与视频具备静态和减少动效降级。
