# 产品与品牌设计原则

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 总原则

### 1.1 Content Before Effect

业务内容、证据和行动优先于玻璃、发光、3D 与动画。任何视觉效果都必须回答一个问题：它是在说明层级、状态、来源、风险还是品牌？如果没有明确语义，应删除。

### 1.2 AI Must Be Legible

用户必须知道：

- 哪些内容由 AI 生成、推荐或执行；
- AI 已经执行了什么，尚未执行什么；
- 使用了哪些数据、工具和权限；
- 用户可以如何检查、纠正、批准或撤销。

AI 标签是解释入口，不是解释本身。

### 1.3 Controlled Depth

深度只用于区分：基础内容、浮层、当前焦点和临时阻断任务。单页最多设置一个主聚焦层，避免所有卡片都发光和悬浮。

### 1.4 Calm by Default

生产系统默认安静：

- 正常状态弱化；
- 异常、阻塞和待审批突出；
- 动效短、可预测；
- 长时间阅读区域使用实体表面；
- 不用持续流光模拟“智能”。

### 1.5 Trust Through Evidence

企业、金融、运维和 Agent 场景的信任来自证据，而不是“置信度百分比”。界面应优先展示来源、时间、变更、工具结果、权限、日志、引用和复核状态。

### 1.6 Accessible From the Start

无障碍不是最终验收补丁。颜色、结构、焦点、键盘、缩放、动态和文本替代必须在组件 API 和设计稿阶段定义。

## 2. 品牌表达层级

### Level 0 — Neutral

用于金融、运维告警处置、审计、长表格和权限配置。无玻璃或极弱玻璃，无装饰性 3D。

### Level 1 — Productive

用于企业系统和 Agent 工作台的日常操作。允许轻微材质、高光和 AI 标识，但内容仍占主导。

### Level 2 — Expressive

用于工作区欢迎页、Agent 拓扑、成果展示和产品 Demo。可使用明显玻璃、渐变和空间动画。

### Level 3 — Immersive

用于官网 Hero、发布会、概念产品和品牌视频。允许 3D、粒子、镜头、空间叙事，但必须提供性能与无障碍降级。

## 3. AI 视觉语言

AI 视觉不得只依靠绿色。建议将 AI 语义拆分为：

| 语义 | 表达 |
|---|---|
| AI 参与 | AI 标签、轻微光感、来源入口 |
| AI 建议 | 虚线边界或建议底色、可接受/编辑 |
| AI 执行中 | 明确状态、步骤与停止入口 |
| AI 已执行 | 结果、工具、时间和影响记录 |
| AI 风险 | 风险色、权限范围、审批与后果 |
| 人工确认 | 人形图标、审批人、决策时间 |

## 4. 产品与营销边界

产品应用强调完成任务、可预测、稳定和长时间使用；官网和发布会强调理解价值、记住品牌和采取行动。两者可以共享：

- Logo、品牌色和字体；
- 3D 造型语言；
- AI 标签和图标风格；
- Motion 曲线；

但不得直接共享：

- 信息密度；
- 模糊强度；
- 自动播放策略；
- 首屏资源预算；
- 控件尺寸；
- 数据展示和确认机制。

## 5. 文案原则

- 使用行为动词描述按钮：`批准发送邮件`，不要只写 `确认`。
- 危险操作说明对象、数量、环境和可撤销性。
- 区分“建议”“草稿”“已提交”“已执行”。
- 错误信息包含原因、影响和下一步。
- 不使用“智能完成”“一键解决”等无法验证的绝对表述。

## 6. 禁止事项

- 用发光表示所有 AI 内容；
- 用绿色同时表达品牌、成功、在线、盈利和安全；
- 用 3D 代替可扫描的列表；
- 用置信度百分比掩盖缺少来源；
- 在生产环境把危险动作隐藏在图标菜单中；
- 在官网自动播放不可暂停的强运动；
- 把正常状态和异常状态设置为相同视觉权重。
