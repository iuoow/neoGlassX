# 金融与数据系统设计规范

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 目标

帮助用户准确查看、比较、核验、追踪和复核数据。视觉高级感不能替代来源、时间、单位、精度与计算口径。

## 2. Data Trust Pattern

每个关键指标应按需要展示：

```text
Value
Unit / Currency
Source
As-of Time
Timezone
Freshness
Update Frequency
Quality Status
Calculation Method
Version
Confidence / Uncertainty
Adjustment Status
```

示例：

```text
¥1,286,430.25
数据截至：2026-07-29 15:30:00 CST
来源：财务核算系统
刷新周期：5 分钟
状态：已核对
```

## 3. 数字格式

必须定义：

- 币种与符号位置；
- 千位分隔符；
- 小数位；
- 舍入规则；
- 负数格式；
- 百分比基数；
- 大数缩写；
- 科学计数；
- 零值、空值、未知和不可用；
- 估算值、预测值和实际值。

`0`、`—`、`N/A`、`未知`、`无权限` 不得混用。

## 4. 时间与实时性

- 所有实时或近实时数据展示最后更新时间；
- 跨区域系统展示时区；
- 图表和表格共享同一时间范围；
- 延迟数据使用显著但非危险的 Freshness 状态；
- 自动刷新支持暂停；
- 刷新频率与数据变化速度匹配。

## 5. 数据来源与血缘

指标详情可展开：

```text
源系统
数据集 / 表
计算公式
转换步骤
负责人
质量规则
最近变更
下游影响
```

AI 生成的分析必须关联底层数据、查询或引用，不以自然语言替代证据。

## 6. 对账与复核

支持：

- 版本比较；
- 期初 / 期末；
- 账面 / 实际；
- 来源 A / 来源 B；
- 预测 / 实际；
- 调整前 / 调整后；
- 差异原因；
- 复核人和时间；
- 导出凭证。

## 7. 金融操作风险

涉及交易、转账、资金、额度或发布正式报表时，至少采用 R4：

- 展示金额、币种、账户和目标；
- 显示费用、汇率和时间；
- 二次确认或审批链；
- 不在 Toast 中完成最终确认；
- 提供不可撤销说明；
- 生成审计记录。

## 8. 视觉策略

- 默认 Compact；
- 使用等宽数字；
- 玻璃 None / Low；
- 颜色严格语义化；
- 盈亏、涨跌不能只靠红绿；
- 预测区域使用区间或纹理；
- 关键数据提供表格替代。

## 9. 验收

- 数字、币种、单位和小数位一致；
- 所有时间均能确认时区；
- 数据来源和新鲜度可见；
- 导出结果与当前筛选、排序和权限一致；
- 图表能够回到明细数据；
- 预测、估算和实际明确区分。
