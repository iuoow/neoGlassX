# 性能与降级策略

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 性能等级

```text
Full      高性能设备与完整视觉
Balanced  默认生产配置
Reduced   低性能或减少透明/动态
Static    无 WebGL、打印、截图、离线备份
```

## 2. 产品应用预算

项目需根据真实环境设置具体数值，最低应建立以下门禁：

- App Shell 尽快可交互；
- 大表格虚拟化；
- 滚动过程避免布局抖动；
- 实时数据按变化频率刷新；
- 非可视 3D 和动画停止；
- 长日志增量加载；
- 图表数据采样或聚合；
- 模型流式输出批量更新，避免逐 Token 重排整页。

## 3. 官网指标

- 至少 75% 的真实访问 LCP ≤ 2.5 秒；
- 使用真实用户监控而不只依赖本地 Lighthouse；
- Hero 关键资源可发现并优先加载；
- 第三方脚本受预算控制；
- 3D 和视频不阻塞标题与 CTA。

## 4. 玻璃性能

- 大型滚动容器避免多层 `backdrop-filter`；
- 玻璃只用于有限浮层；
- Reduced 模式改为实体背景；
- 高对比模式关闭无必要透明；
- 移动端降低模糊半径和叠加层数。

## 5. 3D / WebGL

- 延迟加载；
- 非可见暂停；
- 限制纹理、粒子和后处理；
- 低端设备降低 DPR；
- 无 WebGL 提供静态替代；
- 避免依赖 3D 完成关键操作；
- 发布会提供离线视频与图片备份。

## 6. 实时数据

- 显示刷新频率和最后更新时间；
- 页面隐藏时降低频率；
- 用户可暂停；
- 数据积压或断连可见；
- 使用批量更新；
- 告警和财务数据避免无意义高频刷新。

## 7. Agent 流式界面

- 文本分批渲染；
- 工具日志默认折叠；
- 大 Artifact 延迟预览；
- 文件树按需加载；
- 历史 Run 分页；
- 执行时间线使用虚拟化；
- 断线后支持恢复状态而非重复执行。

## 8. 降级顺序

```text
关闭背景粒子
→ 关闭视差和漂浮
→ 降低模糊
→ 停止非关键动画
→ 3D 替换为 2D
→ 视频替换为 Poster
→ 图表替换为简化图 / 表格
```

关键内容、审批和危险操作不得在降级中消失。

## 9. 监控

记录：

- Core Web Vitals；
- 页面加载和交互延迟；
- 长任务；
- WebGL 初始化失败；
- 图表渲染时间；
- 实时连接重连；
- Agent 流式断线；
- 降级模式使用率。

## 10. 验收

- 低性能设备仍可完成核心任务；
- 减少动态和透明模式不缺失信息；
- 无 WebGL 官网仍可理解与转化；
- 实时断连不会伪装为正常；
- 断线恢复不会重复高风险 Agent 行为。
