## 8. 使用说明

- 优先引用官方文档和一手资料；
- 快速演进项目在设计评审时重新确认功能状态；涉及具体功能时记录访问日期、版本或 commit；
- 引用 GitHub 上的参考实现时，架构依据优先固定到 tag 或 commit，而不是长期指向 `main`；
- 外部资料用于建立原则和参考，不应取代具体业务研究、用户测试和法律合规评审；
- 本索引记录的是 v0.2 编写时的参考基线。
