# 核心组件设计规范

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 核心组件范围

核心组件必须跨 Agent、企业、金融、运维和营销后台复用，不携带特定业务语义。

```text
Navigation
Actions
Inputs
Data Display
Feedback
Overlays
Layout
Utilities
```

## 2. 完整状态模型

所有交互组件至少定义：

```text
Default
Hover
Pressed
Focus-visible
Selected
Disabled
Read-only
Loading
Success
Warning
Error
```

当状态冲突时优先级：

```text
Disabled > Error > Focus > Pressed > Selected > Hover > Default
```

## 3. 导航组件

### App Shell

支持：

- 顶部导航；
- 左侧展开与收起导航；
- 工作区 / 租户切换；
- 全局搜索；
- 命令面板；
- 通知；
- 用户与环境标识。

生产、测试和演示环境必须有持续可见的环境标记。

### Navigation Item

- 当前项不能只依赖颜色；
- 支持图标、文字、徽标和层级；
- 图标折叠模式必须提供 Tooltip；
- 二级层级不建议超过三层。

## 4. Action 组件

### Button

```text
Primary
Secondary
Ghost
Tertiary
Danger
Icon
Split
```

按钮文案描述行为和对象。高风险按钮不得仅显示图标。

### Action Bar

用于批量操作、审批、事件处置和 Agent Run 控制。操作栏必须展示已选择对象数量，并支持清除选择。

## 5. 输入组件

- Text Input
- Textarea
- Select / Combobox
- Checkbox / Radio / Switch
- Date / Time / Timezone
- Number / Currency / Percentage
- Search
- Filter Builder
- Code / JSON Editor
- Secret Input

Secret Input 默认遮蔽，复制、显示和替换操作需记录安全事件。

## 6. 数据展示组件

### Data Table / Data Grid

必须支持：

- 固定表头与列；
- 排序、筛选、搜索；
- 列显示配置；
- 多选与批量操作；
- 虚拟滚动；
- 空值、未知、无权限三种状态；
- 行级与字段级权限；
- 键盘网格导航；
- 导出范围说明。

### Card

卡片不是默认布局单位。只有当内容可以独立理解、操作或移动时使用卡片。高密度数据优先列表和表格。

### Context Panel

替代 v0.1 的固定“任务详情栏”，支持：

- 任务详情；
- Agent Run；
- 告警；
- 数据指标；
- 用户或权限对象；
- 文件与产物。

面板应支持固定、浮动、全屏和返回原上下文。

## 7. Feedback 组件

- Inline Message
- Toast
- Banner
- Empty State
- Skeleton
- Progress
- Error State
- Connection State
- Read-only State
- Degraded Mode

Toast 不用于必须保留、必须处理或包含重要证据的信息。

## 8. Overlay 组件

- Tooltip
- Popover
- Dropdown
- Drawer
- Modal
- Command Palette

Modal 只用于阻断式决策；复杂编辑应进入页面或大型 Drawer。打开后必须管理焦点，关闭后焦点返回触发元素。

## 9. 组件文档模板

每个组件必须包含：

```text
Purpose
When to use
When not to use
Anatomy
Variants
States
Behavior
Content rules
Accessibility
Responsive
Performance
Analytics events
API mapping
Examples
Do / Don't
Changelog
```

## 10. 组件验收

- 所有状态在 Light、Dark、High Contrast 下通过；
- Compact 与 Comfortable 不破坏语义结构；
- 键盘、屏幕阅读器和 200% 缩放可用；
- 错误、加载和无权限状态完整；
- 组件不依赖页面级 CSS 修复；
- API 与 Figma Variant 一一映射。
