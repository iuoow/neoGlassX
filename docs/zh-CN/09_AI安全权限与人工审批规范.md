# AI 安全、权限与人工审批规范

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 目标

将 Agent 的工具权限、外部副作用、Prompt Injection、Secret、记忆和供应链风险转化为用户可理解、可控制和可审计的界面。

## 2. 风险模型

| 等级 | 典型行为 | 默认策略 |
|---|---|---|
| R0 | 读取公开信息、无副作用计算 | 自动执行并记录 |
| R1 | 创建草稿、本地产物 | 执行后通知 |
| R2 | 修改内部资源、写入非关键系统 | 策略审批或执行前确认 |
| R3 | 外发、发布、删除、生产写入 | 明确人工审批 |
| R4 | 财务、权限、密钥、不可逆关键操作 | 强审批、身份验证、完整审计 |

风险由动作、对象、环境、数据敏感度、可撤销性和规模共同决定，不能只按工具名称判断。

## 3. Approval Card

必须展示：

```text
Agent 要做什么
目标对象和环境
影响数量 / 范围
使用的工具
将读取或发送的数据
风险等级
是否可撤销
预计成本 / 时长
请求原因
审批有效时间
拒绝后的行为
```

按钮文案示例：

```text
批准向 24 位客户发送邮件
允许在生产环境执行只读查询
拒绝并要求 Agent 修改计划
```

## 4. 最小权限

权限界面按以下层级配置：

```text
Agent
→ Tool
→ Action
→ Resource Scope
→ Environment
→ Time Window
→ Conditions
```

显示权限继承、临时授权和最近使用。长期未使用的高权限应提示收回。

## 5. Prompt Injection 与不可信内容

对来自网页、邮件、文件、RAG 和第三方工具的内容标记来源与信任边界。Agent 不应把外部内容中的指令默认视为系统指令。

UI 应展示：

- 不可信来源标识；
- 检测到的可疑指令；
- 被阻止的工具调用；
- 数据外发目标；
- 用户覆盖策略和后果。

## 6. Secret 管理

- Secret 默认不回显；
- Skill / Tool 显示需要哪些 Secret，但不显示值；
- 作用域区分 Agent、Workspace、Tenant、Environment；
- 复制、显示、修改和导出产生审计事件；
- 日志、截图和 Artifact 自动脱敏。

## 7. Skill 与插件供应链

安装前展示：

- 来源、作者和签名；
- 版本；
- 权限；
- 依赖；
- 网络目标；
- Secret；
- 最近更新；
- 安全扫描；
- 社区或组织信任状态。

升级时展示权限变化 Diff。

## 8. Memory 安全

长期记忆写入显示来源、内容摘要、敏感度、范围、保留期和删除入口。对身份、财务、健康、凭证和组织机密等敏感信息采用更严格策略。

## 9. 审计与证据

每个高风险事件记录：

```text
Actor
Agent / Model
Run ID
Time / Timezone
Tenant / Environment
Tool
Input Summary
Approval
Result
Resource Diff
Trace ID
Rollback / Compensation
```

## 10. 安全状态

```text
Allowed
Needs Approval
Denied by Policy
Blocked as Suspicious
Expired Permission
Secret Missing
Sandbox Violation
Partial Side Effect
Rollback Required
```

## 11. 验收

- 用户能理解审批的具体后果；
- Secret 不出现在普通 UI 和日志；
- 外部副作用可追溯；
- Prompt Injection 风险有可见信任边界；
- 权限遵循最小范围和最短时间；
- 高风险失败提供补偿或人工处置路径。
