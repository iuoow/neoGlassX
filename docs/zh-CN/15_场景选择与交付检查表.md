# 场景选择与交付检查表

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 选择主 Profile

| 问题 | Agent | Enterprise | Finance | Ops | Marketing |
|---|---:|---:|---:|---:|---:|
| 是否监督模型执行和工具调用 | ★★★ | ★ | ★ | ★ | ★ |
| 是否以结构化业务处理为主 | ★ | ★★★ | ★★ | ★★ | — |
| 是否强调精度、来源和复核 | ★★ | ★★ | ★★★ | ★★ | ★ |
| 是否处理告警、事件和恢复 | ★ | ★ | ★ | ★★★ | — |
| 是否强调传播、叙事和转化 | ★ | — | — | — | ★★★ |

一个产品可有主 Profile 和次 Profile，例如：

```text
OpenClaw 控制台：Agent + Enterprise
AI 金融研究台：Agent + Finance
AIOps 平台：Ops + Agent
企业官网：Marketing + Agent Demo
```

## 3. Agent 产品清单

- [ ] Agent / Session / Run 对象已区分
- [ ] 计划、执行和产物可追踪
- [ ] Tool Call 有摘要、结果和风险
- [ ] 高风险行为有审批
- [ ] 多 Agent Handoff 可见
- [ ] Skill 来源、权限和 Secret 可见
- [ ] Memory 可审核和删除
- [ ] Automation 有时区、下次运行和失败状态
- [ ] 断线恢复不会重复副作用

## 4. 企业产品清单

- [ ] 多租户与环境持续可见
- [ ] 权限、继承和数据范围可解释
- [ ] 表格支持保存视图和批量操作
- [ ] 复杂表单支持草稿和错误摘要
- [ ] 审批流程可追溯
- [ ] 审计日志可复原关键动作
- [ ] 导出范围与权限一致

## 5. 金融与数据清单

- [ ] 币种、单位、精度和舍入明确
- [ ] 时间与时区明确
- [ ] 来源、口径和新鲜度可见
- [ ] 实际、预测和估算区分
- [ ] 图表可回到明细
- [ ] 高风险财务操作使用 R4
- [ ] 导出可以复核

## 6. 运维清单

- [ ] Dashboard 回答明确问题
- [ ] 异常可下钻到指标、日志和链路
- [ ] 告警支持确认、分组、静默和升级
- [ ] 事件有时间线、负责人和 Runbook
- [ ] 处置动作可审计
- [ ] 实时刷新可暂停
- [ ] 复盘有根因和行动项

## 7. 官网与发布会清单

- [ ] 无 3D 时仍能理解价值和点击 CTA
- [ ] Demo 区分真实与概念
- [ ] LCP 目标与监控已建立
- [ ] 3D、视频和字体有预算
- [ ] Reduced Motion 可用
- [ ] 无 WebGL 有静态替代
- [ ] 发布会有离线备份
- [ ] Structured Data 与可见内容一致
