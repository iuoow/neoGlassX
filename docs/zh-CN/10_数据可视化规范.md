# 数据可视化规范

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 基本原则

每个 Dashboard 和图表必须回答问题、支持决策或触发行动。图表数量不是价值，减少认知负荷优先。

## 2. 图表选择

| 问题 | 推荐图表 |
|---|---|
| 趋势如何变化 | 折线图、面积图 |
| 类别比较 | 条形图、点图 |
| 构成是什么 | 堆叠条形、100% 堆叠 |
| 分布如何 | 直方图、箱线图 |
| 两变量关系 | 散点图 |
| 流向和血缘 | 桑基图、关系图 |
| 层级结构 | 树图、分层列表 |
| 服务依赖 | 拓扑图 + 列表 |
| 计划依赖 | DAG + 步骤列表 |
| 时间与事件 | 时间线、事件标记 |
| 财务价格 | K 线、成交量、深度图 |

饼图只用于极少类别、总和明确且不需要精确比较的场景。

## 3. 图表必须定义

```text
Purpose
Question
Data source
Unit
Time range
Timezone
Aggregation
Null handling
Zero handling
Negative values
Precision
Color semantics
Tooltip
Legend
Interaction
Export
Accessibility alternative
```

## 4. 颜色

- 业务状态颜色稳定；
- 品牌色不占用全部数据系列；
- 不使用彩虹色；
- 同一维度跨页面保持颜色一致；
- 异常可使用颜色、形状、线型和标签组合；
- 色觉缺陷下仍可区分关键系列。

## 5. 时间序列

- 明确采样与聚合；
- 不同单位使用独立轴或拆图；
- 标记部署、配置和事件；
- 空白区分“无数据”与“值为零”；
- 实时模式显示窗口、延迟和刷新状态；
- 自动刷新可暂停。

## 6. 预测与不确定性

- 预测与实际使用不同线型；
- 显示预测区间；
- 标注模型、生成时间和版本；
- 不把单一预测线表现为确定事实；
- AI 文本总结关联图表范围和数据来源。

## 7. 拓扑和关系图

- 节点过多时聚合；
- 提供搜索、过滤和列表；
- 边的方向与语义明确；
- 不依赖动画理解关系；
- 3D 仅在空间关系确有价值时使用。

## 8. 表格替代

关键图表必须提供：

- 数据表；
- 下载；
- 文本摘要；
- 屏幕阅读器标题与说明；
- 键盘可访问数据点或替代详情。

## 9. Dashboard 结构

```text
目的和范围
→ 关键状态
→ 主要趋势
→ 异常与原因
→ 可操作明细
→ 文档 / Runbook / 数据说明
```

## 10. 验收

- 10 秒内可以回答 Dashboard 的核心问题；
- 图表标题描述业务问题而非仅写指标名；
- 单位、时区、来源和刷新状态可见；
- 异常可下钻；
- 颜色不是唯一信息通道；
- 可导出数据与视觉筛选一致。
