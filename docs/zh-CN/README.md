# Neo-Glass AI 与企业体验设计系统

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 系统定位

本设计系统不是一套固定的“暗色任务管理 Dashboard 皮肤”，而是一套可组合的体验架构：

```text
品牌基础层
  ↓
核心产品设计系统
  ↓
场景 Profile
  ↓
具体产品、业务主题与交付物
```

Neo-Glass 负责品牌辨识、空间层级和 AI 视觉表达；业务架构、交互模型和安全边界由各场景 Profile 决定。

## 2. 为什么升级

归档的 [`v0.1 任务管理 UI 规范`](../archive/v0.1/暗色_Neo-Glass_企业任务管理平台_UI设计规范建议稿_v0.1.md) 主要围绕任务、项目、KPI、看板和右侧详情展开，适合概念型任务管理产品，但不足以统一承载：

- OpenClaw、Hermes Agent 一类 Agent 控制面与执行工作台；
- 多租户、权限、审批、审计和批量操作的大型企业系统；
- 强调精度、来源、时区、数据新鲜度和可追溯性的金融与数据系统；
- 告警、事件、日志、指标、链路和 Runbook 驱动的运维平台；
- 强品牌、3D、视频、滚动叙事和转化路径驱动的官网或发布会页面。

## 3. 当前产品参考基线

本系统将 OpenClaw 与 Hermes Agent 作为 Agent 产品形态参考，而不是要求所有产品复制其信息架构。

- OpenClaw Control UI 当前包含按 Agent 作用域管理的 Skills、Skill Workshop、会话与控制能力；其 Workboard 是与 task、run、dashboard session 关联的可选轻量看板；后台自动化覆盖任务、计划作业、事件钩子和持续指令。
- Hermes Agent 当前强调持久化多 Agent Kanban、独立进程 Worker、Profile 边界、记忆、Skill 自我改进和定时自动化。

因此，Agent Profile 必须把 `Agent / Session / Run / Plan / Tool Call / Approval / Skill / Memory / Artifact / Automation / Node` 作为一等对象，而不是只在任务详情中增加一张“AI 建议卡”。

## 5. Profile 选择

| Profile | 首要目标 | 默认密度 | 默认玻璃强度 | 默认动效 |
|---|---|---:|---:|---:|
| Agent Workbench | 监督理解、计划、执行与交付 | Compact | Solid；仅局部 Subtle Glass | Productive |
| Enterprise | 高效处理结构化业务 | Compact | Solid | Productive |
| Finance & Data | 精确查看、核验与追溯数据 | Compact | Solid | Minimal |
| Operations | 快速发现、诊断和恢复故障 | Compact | Solid | Minimal |
| Marketing & Launch | 解释价值、建立品牌并转化 | Comfortable / Presentation | High | Expressive |

## 6. 使用顺序

1. 阅读 `01_产品与品牌设计原则.md`。
2. 从 `15_场景选择与交付检查表.md` 选择主 Profile 和次 Profile。
3. 采用 `02_核心Design_Token规范.md` 建立用户偏好、体验等级和 Profile 预设；不要把 Risk 当成整页主题。
4. 从 `03_核心组件设计规范.md` 选用基础组件。
5. 加载对应场景 Profile，禁止用官网视觉规则直接覆盖生产系统。
6. 使用安全、无障碍、性能和治理规范进行验收。

## 7. 核心决策

- **Neo-Glass 是体验能力，不是信息架构。**
- **3D 是可选品牌能力，不是核心业务组件。**
- **AI 样式只标识 AI 参与，不代替可解释性。**
- **高风险 Agent 行为必须可理解、可审批、可审计；Risk 绑定具体操作，而非页面。**
- **产品界面与营销传播共享品牌语言，但使用不同的密度、动效和性能预算。**
- **所有前景与背景组合必须实际测试，而不是仅凭透明度推测对比度。**

## 8. 版本边界

v0.2 完成设计系统架构、对象模型、规范边界与验收规则；它还不是最终高保真视觉稿，也不包含特定品牌 Logo、业务字段和产品文案。正式设计前仍需确定产品主 Profile、首版页面范围和交付技术栈。
