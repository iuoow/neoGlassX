## 1. 首发定位

`v0.2.0-alpha.1 — Architecture Preview` 公开的是架构、规范边界和贡献方式，不宣称已经提供稳定组件库、完整 Figma Kit、生产级 Token API 或安全/无障碍认证。

公开页面必须清晰标记：

```text
Documentation-first
Experimental
No stable public API
Not a production template
```

## 2. 首个纵向参考实现

不要同时实现五个等权 Profile。首个可运行示例固定为：

```text
Agent Run Workspace
  ├─ Goal and run summary
  ├─ Execution Timeline
  ├─ Tool Call disclosure
  ├─ Approval Card
  ├─ Artifact Workspace
  └─ Audit evidence
```

它必须证明以下链路能够闭环：

```text
目标 → 计划 → 工具调用 → 风险判断 → 人工审批 → 证据 → 产物 → 审计
```

## 4. 通过门槛

一个组合只能被标记为“supported”，当且仅当它具备：

1. 可追踪的 Token mapping；
2. 参考页面或组件样例；
3. 键盘、对比度、缩放和动态降级证据；
4. 视觉回归或人工基准；
5. 相关风险、隐私和性能说明。

没有上述证据的组合只能标记为 `experimental` 或 `planned`。
