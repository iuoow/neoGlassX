# 无障碍与国际化规范

> **版本**：v0.2  
> **状态**：Architecture Preview；规范优先，非稳定组件 API  
> **更新日期**：2026-07-29  
> **适用范围**：AI Agent 工作台、企业系统、金融与数据平台、运维与可观测平台、官网、概念产品与发布会  


## 1. 目标等级

Web 产品以 WCAG 2.2 AA 为最低目标；关键产品可针对 Focus Appearance 等 AAA 条目采用更高标准。

## 2. 对比度

- 普通文字至少 `4.5:1`；
- 大文字至少 `3:1`；
- 控件边界和重要图形至少 `3:1`；
- 透明和玻璃背景必须按实际合成结果测试；
- Light、Dark、High Contrast 分别测试。

## 3. 焦点与键盘

- 使用 `:focus-visible`；
- 焦点不被 Sticky、Drawer 或浮层遮挡；
- Modal 打开时焦点进入，关闭时返回；
- 表格、树、菜单和图表采用适当键盘模式；
- 不移除浏览器焦点而不提供替代；
- 可考虑双色 Focus Ring 适配复杂背景。

## 4. 目标尺寸

WCAG 2.2 AA 的最小指针目标为 24×24 CSS px，存在例外；本系统推荐：

- 桌面最小 32×32；
- 主要控件 36–40；
- 触控主要目标 44×44 或更大。

## 5. 缩放与 Reflow

测试：

```text
200% Zoom
400% Zoom
320 CSS px 宽度
文本间距覆盖
系统字体放大
```

不固定高度裁切正文；重要信息不能只在 Hover 中出现。

## 6. 动态与透明度

- 响应 `prefers-reduced-motion`；
- 减少视差、镜头、弹簧和持续动画；
- 提供暂停；
- 响应系统减少透明度能力，并提供产品内实体表面模式；
- 必要状态变化保留简短淡入淡出。

## 7. 屏幕阅读器

- 页面区域和标题层级正确；
- 图标按钮有可访问名称；
- 图表提供标题、摘要和数据替代；
- Toast 使用适当 Live Region；
- Agent 工具调用更新避免高频打断；
- 批量操作说明选择范围。

## 8. 国际化

支持：

- 文本长度增长 30%–100%；
- RTL；
- 中文、英文、日文等字体回退；
- 名字顺序和地址格式；
- 日期、时间、时区；
- 数字、百分比、币种；
- 复数和量词；
- 本地化排序和搜索。

不在代码中拼接可见句子。

## 9. 金额与数字

使用 locale-aware 格式化，不假设符号、千位、小数位和负数形式。产品应明确数据的币种，而不是仅显示符号。

## 10. 测试矩阵

```text
Keyboard only
NVDA + Chrome / Edge
VoiceOver + Safari
200% / 400% zoom
High contrast
Reduced motion
Reduced transparency
Color vision simulation
Light / Dark
Windows / macOS
Touch device
```

## 11. 验收

- 核心任务可只用键盘完成；
- 状态不只靠颜色；
- 动态更新不会持续打断；
- 语言切换不破坏布局；
- 时间与数字格式正确；
- 玻璃和 3D 降级后仍保留完整信息。
