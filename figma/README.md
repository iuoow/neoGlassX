# Figma

该目录用于记录 Figma Community Kit、Libraries、Variables 和组件发布策略。

## 计划内容

- Core Foundations
- Variables / Tokens Mapping
- Core Components
- Agent Workbench Patterns
- Enterprise Patterns
- Finance & Data Patterns
- Operations Patterns
- Marketing and Launch Assets
- Accessibility Annotations
- Prototype Examples

## 发布要求

- 文件版本与仓库 Release 对应
- 组件成熟度明确
- Token 与 Variables 映射可追踪
- 字体、图标和图片许可证清楚
- 不包含客户数据或未授权第三方界面
- 社区文件注明官方与实验组件
