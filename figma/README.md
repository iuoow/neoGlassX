# Figma

该目录包含 Figma Community Kit 的可交付蓝图、Variables 映射和发布清单。
它不是可导入的 `.fig` 二进制文件；完整 Figma 文件仍需在 Figma 中由维护者
创建、审阅并发布。

## 当前交付

- [`COMMUNITY_KIT.md`](./COMMUNITY_KIT.md)：页面、组件、变量与发布准则。
- [`community-kit.manifest.json`](./community-kit.manifest.json)：可机读的首发
  范围、成熟度和 Token 来源。

## Kit 范围

- Core Foundations
- Variables / Tokens Mapping
- Core Components
- Agent Workbench Patterns
- Enterprise Patterns
- Finance & Data Patterns
- Operations Patterns
- Marketing and Launch Assets
- Accessibility Annotations
- Prototype Examples

## 发布要求

- 文件版本与仓库 Release 对应
- 组件成熟度明确
- Token 与 Variables 映射可追踪
- 字体、图标和图片许可证清楚
- 不包含客户数据或未授权第三方界面
- 社区文件注明官方与实验组件
